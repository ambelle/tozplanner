# DreamMS TOZ Train Manager

Static GitHub Pages planner for 7-round Tower of ToZ trains.

## Features
- 7 rounds with 6 slots per round
- Belle and Gillian characters preloaded
- Public player input with round availability
- Drag/drop party planning
- Role dependency checks
- Missing Dispel / FMA / SE / TH / SI warnings
- SE-only checks for Night Lord, Night Walker, and Evan
- Character clear tracker for Belle + Gillian
- Suggested fills from the lobby
- Local save, import, and export

## How to use on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `app.js`, and `README.md`.
3. Go to Settings → Pages.
4. Set source to Deploy from branch → main → root.
5. Open the generated GitHub Pages link.

## Notes
This version is local-browser only. For live public signups, connect it later to Google Sheets or Firebase.
